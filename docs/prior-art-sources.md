- AgentCore Runtime direct Python deployment: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-get-started-code-deploy-python.html
- Xabier Muruaga, **Bounded Agents: Delegation Security for Multi-Agent AI Systems**, arXiv:2608.15888: https://arxiv.org/abs/2608.15888

These sources eliminate generic claims that the project invented tool-level HITL, interrupt/resume, delegated authorization, or agent hosting. The competition thesis remains the policy-bounded semantic Authority Cut plus externally held human authority and correction-driven selective compensation.
